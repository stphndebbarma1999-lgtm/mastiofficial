What is a Masti Host?

A Masti Host is an individual user who joins the Masti App personally and participates in supported interactive features according to current eligibility requirements and platform policies.

Hosts are different from a Masti Agency, which focuses on recruiting and managing multiple hosts. Some visitors also search using terms like Masti Anchor App while looking for host joining information — this page covers the host joining process in detail.

How Masti Hosts Participate

Calls

Participate in supported call-based interaction features.

Virtual Gifts

Receive supported virtual gifts where applicable.

Activity Programs

Take part in applicable host activity programs.

Performance Programs

Access programs available to eligible active hosts.
